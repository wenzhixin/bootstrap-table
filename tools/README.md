# Tools

## Install

```
yarn install
```

## List

* check-api: Check the docs API
* check-locale: Check the src locale
* create-d-ts: Generate `index.d.ts` and `tests/types/generated-options.test.ts` from runtime defaults

## TypeScript definitions

`index.d.ts` is generated by `yarn types:build` (`tools/create-d-ts.js`) from
`src/constants/index.js` and every extension's `Object.assign` defaults. Do not
edit it by hand. Precise signatures live in `tools/type-overrides.js`; the
`pre-commit` chain runs `yarn types:check` to reject a stale generated file.
