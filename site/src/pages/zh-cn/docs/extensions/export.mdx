数据导出扩展可以将表格数据导出为多种格式，包括 JSON、XML、CSV、TXT、SQL 和 Excel。

本扩展已内置导出实现，不再依赖任何外部插件。

> **注意**
>
> 已废弃的 [tableExport.jquery.plugin](https://github.com/hhurz/tableExport.jquery.plugin) 已被移除，
> 因此 `png`、`pdf`、`xlsx`、`doc`、`powerpoint` 这些格式**不再支持**。
> 导出内容取自表格的数据模型而非渲染后的 DOM，所以 `ignoreColumn`、`csvSeparator`、`csvEnclosure`、
> `ignoreRow`、`displayTableName` 等旧插件选项不再生效。
> 如果确实需要上述格式，请使用 SheetJS、jsPDF 等第三方库配合 `getData` 方法自行实现。

## 用法

```html
<script src="extensions/export/bootstrap-table-export.js"></script>
```

## 选项

### showExport

- **属性:** `data-show-export`

- **类型:** `Boolean`

- **详情:**

  是否在工具栏显示导出按钮。设置为 `true` 时，用户可以通过点击导出按钮下载表格数据。

- **默认值:** `false`

### exportDataType

- **属性:** `data-export-data-type`

- **类型:** `String`

- **详情:**

  设置导出数据的范围：
  * `'basic'`：仅导出当前页数据
  * `'all'`：导出所有页的全部数据
  * `'selected'`：仅导出选中的行，未选中任何行时不导出

  导出的列由 `visible`、`forceExport`、`forceHide` 列选项决定，复选框/单选框状态列始终会被跳过。
  单元格取值为 formatter 的处理结果并去除其中的 HTML 标签，即与表格中显示的内容一致。

- **默认值:** `basic`

### exportFooter

- **属性:** `data-export-footer`

- **类型:** `Boolean`

- **详情:**

  是否同时导出表格页脚。设置为 `true` 时，页脚会作为最后一行追加到导出的文件中，
  每个导出列的值由该列的 `footerFormatter` 决定。

- **默认值:** `false`

### exportOptions

- **属性:** `data-export-options`

- **类型:** `Object`

- **详情:**

  内置导出器的配置选项：

  - `fileName`：`String` 或 `Function`，导出文件名（不含扩展名，默认为 `table`）。
  - `csvDelimiter`：`String`，`csv` 与 `excel` 类型使用的分隔符（默认为 `,`）。
  - `tableName`：`String`，`sql` 与 `xml` 类型使用的表名（默认为 `table`）。

  调用 `exportTable` 方法时传入的参数会合并到这些选项中，例如：

  ```js
  $('#table').bootstrapTable('exportTable', { type: 'csv', fileName: 'my-report' })
  ```

  其中 `exportOptions.fileName` 可以是字符串或函数，用于设置导出文件的名称：

  ```js
  exportOptions: {
    fileName: function () {
      return 'exportName'
    }
  }
  ```

### exportTypes

- **属性:** `data-export-types`

- **类型:** `Array`

- **详情:**

  设置可用的导出格式列表。内置支持的格式包括：
  `json`、`xml`、`csv`、`txt`、`sql`、`excel`。
  注意：`png`、`xlsx`、`pdf`、`doc`、`powerpoint` 不再支持。

  * `csv`/`txt`：按分隔符拼接各行，CSV 文件会写入 UTF-8 BOM 并使用 `CRLF` 换行，
    以保证表格软件不会错误识别编码。
  * `json`：每行是一个以列 `field` 为键的对象（而非以列标题为键）。
  * `xml`：根元素来自 `exportOptions.tableName`，每行是一个 `<row>` 节点，
    子节点名称由列 `field` 生成并会被处理为合法的 XML 名称。
  * `sql`：生成一条 `INSERT INTO` 语句，若没有可导出的行则不生成文件。
  * `excel`：**生成的是 CSV 内容，扩展名为 `.xls`**，并不是真正的 Excel 文件，
    打开时 Excel 会提示"文件格式与扩展名不一致"。

  不支持的格式会被跳过：`exportTable` 返回 `false` 并在控制台输出警告，
  既不会导出文件，也不会触发 `export-started`/`export-saved` 事件。

- **默认值:** `['json', 'xml', 'csv', 'txt', 'sql', 'excel']`

### 图标配置

- `export`: `'glyphicon-export icon-share'`（导出按钮图标）

## 列选项

### forceExport

- **属性:** `data-force-export`

- **类型:** `Boolean`

- **详情:**

  设为 `true` 时强制导出该列（例如隐藏列）。

- **默认值:** `false`

### forceHide

- **属性:** `data-force-hide`

- **类型:** `Boolean`

- **详情:**

  设为 `true` 时在导出时强制隐藏该列（例如图标列）。

- **默认值:** `false`

## 事件

### onExportSaved

- **jQuery 事件:** `export-saved.bs.table`

- **参数:** `exportedRows`

- **详情:**

  数据导出完成时触发，参数包含：

  * `exportedRows`：已导出的行（取决于 `exportDataType`）。

### onExportStarted

- **jQuery 事件:** `export-started.bs.table`

- **参数:** `undefined`

- **详情:**

  数据收集并导出之前触发。

## 方法

### exportTable

- **参数:** `options`

- **详情:**

  使用自定义选项导出表格。

## 本地化

### formatExport

- **参数:** `undefined`

- **默认值:** `function () { return "Export data" }`
